The internet is scattered.
Agents should read it in one shape.

One typed facade over fifteen platforms — web, YouTube, GitHub, Hacker News, Reddit, RSS, Discourse forums, NSE / BSE and US equities, Indian and Western news. Every call returns the same ReachResult. Every failure carries a runnable fix.

Get started See how it works 
from bharatnet import Reach

reach = Reach()
reach.read("https://news.ycombinator.com/item?id=39000000")
reach.read("RELIANCE", platform="stocks")
reach.research("UPI transaction limits", region="india")
Fifteen platforms · one result shape Scroll

Fifteen platforms, each with its own CLI, auth story and output format. bharatnet health-checks them, routes every request to the backend that currently works — Jina Reader, yt-dlp, gh, Exa, twitter-cli — and normalises what comes back into one envelope. Six channels need no configuration at all; the rest tell you the command that fixes them.

Four verbs

Read a thing. Search a platform. See what's hot. Fan out across all of it.

01 read

Point it at a URL and get content back. Routing is inferred from the host — YouTube gets metadata plus transcript, GitHub issues go through gh, HN returns the comment tree, anything else falls back to Markdown via Jina Reader.

reach.read("https://youtube.com/watch?v=…")
reach.read("https://forum.valuepickr.com/t/…")
reach.read("https://any-blog.com/post")

02 search

Semantic web search through Exa by default, or target a platform directly — GitHub code search, Discourse forums, equity symbol lookup across NSE, BSE and US listings.

reach.search("llm eval frameworks")
reach.search("react hooks", platform="github", kind="code")
reach.search("smallcap IT", platform="discourse")

03 hot

Front pages and trending lists, region-aware. The Indian news pack pulls ET, Mint, The Hindu, TOI and Moneycontrol; Discourse returns top threads by period.

reach.hot("hackernews")
reach.hot("news", region="india")
reach.hot("discourse", period="weekly")

04 research

One query, parallel fan-out across every channel that can answer it, merged into a single bundle. Ask for a report and Claude writes the synthesis on top.

reach.research("vector db pricing", report=True)

One result shape

Per-platform CLIs each have their own output format. bharatnet normalises all of them into one dataclass, so downstream code never branches on where the content came from. 

ReachResult(
    ok=True,
    platform="stocks",
    backend="yfinance",
    kind="document",
    content="# Reliance Industries…",
    meta={"price": 1275.9, "currency": "INR", …},
)

Failures you can act on

Missing tools do not raise opaque errors. Every ReachError subclass carries a .fix — a runnable prescription — and where a fallback exists, bharatnet degrades to it instead of failing. 

try:
    reach.search("react hooks", platform="github")
except SetupRequired as e:
    #  brew install gh && gh auth login
    print(e.fix)

bharatnet doctor returns the same information as a structured health report across every channel at once.

Install

Two commands to the SDK. One line of JSON to the MCP server.

SDK & CLI

uv venv && uv pip install -e .
bharatnet doctor

doctor reports which upstream tools are missing and how to fix each one. Optional: gh, mcporter + exa, twitter-cli, OpenCLI.

MCP server

{
  "mcpServers": {
    "bharatnet": {
      "command": "bharatnet-mcp"
    }
  }
}

Works in Claude Desktop, Claude Code, Cursor or any MCP client. No shell access required on the agent side.
